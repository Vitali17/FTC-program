# FTC Programming Example – Class-Based Architecture
This repository is an educational example project for the FIRST Tech Challenge (FTC) 2024–2025 season: INTO THE DEEP.
It is designed especially for FTC beginners who want to learn how to structure robot code using classes.

The project demonstrates:

How to organize robot functionality into separate classes

Basic principles of clean and readable FTC code

A simple and scalable architecture suitable for learning and future expansion

This repository serves as a learning resource and reference, not as a final competition-ready robot code.
